# Why exact-h H/Z AUC differs between decay-mode pairs

With the canonical exact `h` and the fixed-C likelihood ratio, the validation
cohort gives pi x pi 0.715, rho x rho 0.736, 3pi x 3pi 0.685, although every
hadronic mode has maximal analyzing power once all decay products are used.
This directory separates the two reasons.

1. **3pi: the "exact" h is not the generator's polarimeter.**  The canonical h
   uses the CLEO a1 current (Cherepanov-Veelken), while the sample was
   generated with the TauDecay UFO Kuehn-Santamaria current (rho(770)+rho(1465),
   beta = -0.145).  `polarimeter.py` rebuilds h from an explicit V-A spinor
   amplitude with the generator current; it closes on pi and rho to 1e-7.
   `<h_CLEO . h_generator> = 0.889`, and with the generator h 3pi x 3pi goes to
   0.737.
2. **pi: the visible-pT selection.**  For tau -> pi nu the visible energy
   fraction is h_k (corr 0.998; rho 0.40, 3pi 0.08), so a ~20 GeV threshold
   removes the soft-pion corners that carry the longitudinal H/Z difference
   (C_kk = -1 vs +1).  A re-decay toy with each event's true tau momenta and
   ideal correlations gives 0.736-0.739 for every pair without selection and
   reproduces pi x pi 0.716 / pi x rho 0.725 / rho x rho 0.737 with it.
