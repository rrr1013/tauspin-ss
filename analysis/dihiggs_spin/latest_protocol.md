## Lifetime experiment

Existing 14TeV parametric MC dataset_v2.npz, raw reco event identity (process, sorted source chunk, event), no new source samples. Same original selection (legacy trigger and b-tag response, m_bb<150, MMC>60) plus corrected longitudinal |z0 sinθ|<500 µm in every arm, no d0 cut. Project the stored 3D closest-approach IP onto the transverse track perigee and smear scalar d0 by its stated sigma; smear scalar z0 and multiply by sinθ. Geometry is an implementation correction; resolutions, electron tails and beamspot model remain explicit toy assumptions.

uid modulo3: train0, validation1, exploratory evaluation2. Existing MMC dr-table is built from train0. Same partitions/rows/smearing for all arms and seeds; seed changes initialization only. Train-only input scaling. Table2-informed five-token Transformer proxy (b1,b2,lepton,tau,MET) plus current generous K, exact available additional globals, flavor and lepton MMC-energy fraction in every baseline. Fixed4layer/4heads/d64; the proxy omits GN2 scores, VBF and extra-jet tokens, MMC token, topness and auxiliary parentage objectives. B, B+d0, B+Had, B+d0+Had, three seeds. Had means added reconstructed hadronic observables, not spin-specific information. Validation-loss stopping; a still-improving safety ceiling triggers technical recovery. K/K+d0 GBDT is a same-split sanity comparison. Zero-true-d0 null and declared real-resolution/nonprompt-fake stresses use one seed; stresses do not define calibrated uncertainty bounds.

Validation signal-quantile bins, merged for aggregate background ESS≥25 and expected B≥3, same rule in all arms. Evaluation bins are frozen; report per-component sumw/sumw2, conditional prompt fraction, poor MC support. Joint SLT/LTT likelihood with shared positive group normalisations, per-bin effective-count MC nuisance. Paired evaluation-event Poisson bootstrap; all bins/models fixed. No rescaling to ATLAS significances, κλ errors or HL-LHC combination.

## Spin readout experiment

Existing spin-flat HH sample and fixed h regression. Same event identity and uid train0/validation1/evaluation2. Spin hypotheses are expected-loss copies of each source event; split before duplication prevents cross-hypothesis leakage. Physically non-negative H/Z/W/U density with canonical h sign, Z Cnn=+0.5,Crr=-0.5,Ckk=+1,Bk=-0.147. Unsupported side contributes its marginal, no invented polarimeter. Compare four unit-vector TauPolaris-style observables, the same four weighted by regressed h norms, mean-h6+joint moments9, with common mode flags; add normalized six-vector and raw six-vector controls to distinguish SM transverse coherence discarded by CP-independent Angular4 from vector-norm information and learned joint moments. Compare K, K+angular4, K+mean6, K+joint15. This measures information retained by these readouts on identical h and does not compare reconstruction networks.
